# WakaTime profile dashboard

A dependency-free TypeScript generator for a GitHub profile README. It uses Node.js 24's built-in TypeScript type stripping and the WakaTime API.

## What it renders

- Hourly activity bars for the last 7 days (local timezone).
- A 365-day SVG heatmap.
- Compact rolling 7-day totals, average, active days, best day, languages, projects and editors.
- Claude Code as a highlighted editor row and a dedicated weekly summary.
- AI additions/deletions/sessions/tokens when WakaTime returns those fields for the Claude Code editor.

## 1. Install WakaTime tracking

Install the WakaTime plugin in each editor you want tracked. For Claude Code, use the official WakaTime plugin:

```bash
claude plugin marketplace add https://github.com/wakatime/claude-code-wakatime.git
claude plugin install claude-code-wakatime@wakatime
```

Ensure `~/.wakatime.cfg` contains your normal WakaTime **API key** (the plugin sends heartbeats with it):

```ini
[settings]
api_key = waka_your_write_only_api_key
```

Then run `claude doctor` and use Claude Code. The WakaTime plugin documentation: https://github.com/wakatime/claude-code-wakatime

## 2. Create an OAuth access token for the dashboard

The generator reads your data, so do not use the write-only API key as the GitHub Actions secret.

Create/copy a WakaTime OAuth access token for personal scripts using the **get your OAuth token here** link in WakaTime’s API authentication documentation (sign in first):
https://wakatime.com/developers/

Do not copy the regular write-only API key from the API key settings page. The generator authenticates with `Authorization: Bearer <OAuth access token>`.

The token must have permission for:
- `read_summaries` — daily totals, editors, languages, projects, and AI summary fields.
- `read_heartbeats` — required by the per-day `/durations` endpoint used for the hourly timeline.

WakaTime API authentication and scopes: https://wakatime.com/developers

In the profile repository, add:
- Repository → Settings → Secrets and variables → Actions → **New repository secret**
- Name: `WAKATIME_ACCESS_TOKEN`
- Value: your OAuth access token

Do not commit the token or place it in README, source files, or a public environment variable.

## 3. Add the README markers

Add these exact markers to the profile README:

```markdown
## Coding activity

<!--START_SECTION:CODING_ACTIVITY-->
Dashboard will be generated by GitHub Actions.
<!--END_SECTION:CODING_ACTIVITY-->
```

The workflow replaces the text between the markers. Keep the markers intact.

## 4. Configure your timezone

In the repository:
Settings → Secrets and variables → Actions → Variables → New repository variable

- Name: `WAKATIME_TIMEZONE`
- Value: your IANA timezone, e.g. `Europe/Berlin` or `Asia/Tehran`.

If you don't set it, the workflow uses UTC.

## 5. Enable write permissions

Repository → Settings → Actions → General → Workflow permissions → enable **Read and write permissions**.

The workflow also declares `permissions: contents: write`.

## 6. Add the files

Copy these into the root of your profile repository:

```text
.github/
  workflows/
    coding-activity.yml
scripts/
  index.ts
assets/
  # generated automatically
package.json
```

You do not need to keep the old `athul/waka-readme` workflow. Disable or remove it if it updates the same README section.

## 7. Run it

Push the files, then open Actions → Update coding activity → Run workflow.

The schedule runs at 00:00 and 12:00 UTC. GitHub may delay scheduled workflows during high load; the cron times are not guaranteed exact execution times.

## Notes and limitations

- WakaTime durations are constructed from heartbeats joined using your WakaTime keystroke timeout. They are an activity estimate, not a stopwatch or proof of continuous work.
- The hourly chart groups each duration into local clock hours. The API may return a duration spanning multiple hours; the generator splits it into minute-sized slices.
- The heatmap uses WakaTime's daily summary totals for the last 365 days.
- Claude Code appears in the editor breakdown when the plugin reports it under that editor name. The separate Claude Code section is derived from the same editor summary.
- AI additions, deletions, sessions, and token counts are optional API fields. If your WakaTime account/plugin does not return them for the Claude Code editor, the README says they are not reported instead of inventing values.
- The generated SVG uses GitHub's dark palette. Change the `colors` array in `renderHeatmap` if you want another palette.
- The weekly summary is a rolling 7-day window including today, not a calendar week.
